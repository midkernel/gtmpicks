# GTM Picks

A curated catalog of go-to-market resources for founders doing the work themselves. It includes practical guides, templates, search and AI visibility resources, and skills founders can use with their agents.

Suggest a public resource in a [GitHub issue](https://github.com/midkernel/gtmpicks/issues/new?template=suggest-resource.yml), or open a pull request against `catalog.json`. Tell us which task it helps a founder complete. Maintainers review additions before they reach the site.
